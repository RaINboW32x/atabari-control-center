# GitHub ve Railway Yükleme

1. Bu klasörün içeriğini GitHub deposunun köküne yükleyin.
2. Railway uygulama servisini bu depoya bağlayın.
3. PostgreSQL servisi ekleyip `DATABASE_URL` referansını uygulamaya tanımlayın.
4. `PUBLIC_HOST`, `CONTROL_HOST` ve `APP_URL` değişkenlerini girin.
5. Railway Networking bölümünde iki custom domain ekleyin.
6. Natro DNS kayıtlarını Railway talimatına göre oluşturun.
7. Deploy sonrası public ve control adreslerini ayrı ayrı test edin.
