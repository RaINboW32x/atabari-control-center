# ATABARI Control Center

Ekip üyelerine özel rol bazlı yönetim ve operasyon uygulaması.

- Owner / Administrator / Moderator / Streamer
- Operasyon Merkezi
- Sponsor Asistanı
- Kullanıcı ve tema yönetimi
- Natro SMTP ve şifre sıfırlama
- Alan adı: `https://control.atabari.live`

## Railway
Bu klasörü ayrı GitHub reposuna yükleyin: `atabari-control-center`.
Railway'de ayrı servis oluşturup ATABARI Web ile aynı PostgreSQL servisinden `DATABASE_URL` referansı ekleyin.
Custom Domain olarak `control.atabari.live` bağlayın.
